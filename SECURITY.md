# Security

The latest released version is supported. Keep the extension and browser updated.

Report security vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/shookapic/pinterest-unblocker/security/advisories/new) when available. If private reporting is unavailable, open an issue requesting a private contact without including exploit details, credentials, or private content.

Include the affected version, reproduction steps, impact, and a minimal example where possible. Ordinary layout and compatibility problems belong in the public bug tracker.

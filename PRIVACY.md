# Privacy policy

Effective date: October 7, 2026

Pinterest Unblocker does not collect, store, or transmit personal data.

The extension runs locally on the Pinterest domains listed in its manifest. It reads page elements to identify supported login overlays, hides those overlays, restores scrolling, and prevents site context-menu handlers from intercepting image right-clicks.

It does not record browsing history, search terms, images, credentials, or account information. It uses no analytics, telemetry, cookies, external servers, or remote scripts. It does not access extension storage.

Image saving is performed by the browser's native **Save image as…** command. Normal Pinterest page requests and browser-initiated image downloads are handled by Pinterest and the browser, independently of this extension.

To stop page changes, disable or remove the extension and reload affected tabs.

Privacy questions can be raised through the project's repository issue tracker.
